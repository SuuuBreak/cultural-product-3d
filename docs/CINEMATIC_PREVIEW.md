# 沉浸叙事样片验收

## 体验入口

- `/`：全新四章叙事首页。
- `/explore`：保留的可旋转 3D 概念展厅，独立按需加载。

首页是可交互网页：静态概念影像通过慢镜头、滚动和取景变换进行叙事，没有冒充实拍视频或真实三维模型。

## 本次验收结果

2026-10-22，正式构建产物使用 Chromium / Playwright 验收：

- `npm run build`：TypeScript 与 Vite 成功。3D 独立模块仍有非阻断的大小提示。
- `npm run lint`：无错误；原模型模块保留一条 Fast Refresh 导出提示。
- 桌面 1440 × 900、手机 390 × 844 与 320 × 844：未发现横向溢出。
- 默认静音，首次点击后创建音频上下文；检测到真实音频信号，关闭时暂停音频上下文，再次点击可恢复。
- 自动观赏推进、暂停、继续、滚轮接管均有效。
- 四章跳转、角色细节展开、材质切换及左右方向键切换有效。
- 展映说明支持原生模态对话框、Esc 关闭和焦点管理。
- 减少动态效果模式关闭自动运镜和自动滚动，保留直接跳转。
- 首页不创建 WebGL Canvas、不下载 3D 应用分包；进入 `/explore` 可加载三维 Canvas、操作复位并返回叙事首页。
- 整轮检查没有页面异常或控制台错误。

验收脚本：`scripts/verify-cinematic.mjs`。软件渲染浏览器检查不替代目标手机的触感、音色和流畅度体验；没有声称所有设备的帧率保证。

## 视觉与声音边界

主视觉、工艺近景和生活场景是由参考展板生成的 AI 概念影像，保留总体黑金红配色与毛绒角色特征，但细节并非经过生产确认。主图说明见 `public/cinematic/ASSETS.md`，页面页脚和说明弹窗也已注明。

网页配乐为本地程序合成的五声音阶氛围原型，并非录制的古琴演奏或正式母带。浏览器需要访客首次点击才能播放声音。

原 3D 模型仍是前一版的几何概念模型，其外观还原和毛发质量没有在本次叙事改造中得到新的实物验证。
