# 寻秦 · 墨墨 MO–MO 沉浸叙事与三维展厅

基于用户提供的「寻秦 · 七萌织锦」二维设计提案开发的可运行交互 MVP。React 19 + TypeScript + Three.js + React Three Fiber + Drei + Tailwind CSS 4 + Vite。

## 先看这一版

首页 `/` 现在是一版可以操作的沉浸叙事样片：开场主视觉、角色细节、工艺特写和日常陪伴四个章节。它使用电影感概念影像、轻微运镜、滚动显现、章节导航及程序合成背景音乐。

1. 打开预览地址，点击 **开启沉浸体验**，画面会自动向下推进，并开始播放柔和的合成弦音。
2. 点击底部 **暂停观赏** 可停下；滚轮、触摸或翻页键会自动接管，随后可以自由浏览。
3. 右上角 **声音 开 / 关** 独立控制背景音乐；播放后底部显示音量滑杆。浏览器不允许在没有用户点击时强制有声自动播放。
4. 顶部章节名称或右边短线可直接跳转。角色部分可选择冠饰、表情、衣装；工艺部分可选择云纹、钱饰与流苏，支持方向键切换。
5. 最后一章点击 **进入 3D 自由探索**，打开 `/explore` 中的原三维展厅；右下角可以返回叙事首页。

页面支持 320px 起的手机布局；系统开启「减少动态效果」时停用运镜和自动滚动，保留章节跳转。切换到后台时暂停音乐和自动观赏，回到页面仅恢复此前主动开启的音乐。

**影像说明：** 三张主视觉是参照设计展板生成的 AI 概念影像，并非实物照片，也不是新建的真实三维模型。画面用于验收本次网页的风格、叙事和交互。网页页脚及「关于本次数字展映」已注明。3D 概念模型的还原精度没有因更换首页而改变。

**声音说明：** `src/cinematic/score.ts` 使用 Web Audio 即时合成五声音阶、拨弦谐波、柔和持续音、延迟与混响；没有下载或使用第三方音乐。它是氛围配乐原型，可以后续替换为选定的音乐文件。

三张 WebP 图片合计约 725 KB，中文字体子集约 219 KB，均随项目本地部署。叙事首页脚本约 78 KB gzip；只有进入 `/explore` 才加载 Three.js 等重依赖。

新文件：`src/cinematic/CinematicExperience.tsx`（叙事和交互）、`cinematic.css`（视觉与适配）、`score.ts`（合成音乐）、`src/ExperienceRouter.tsx`（入口分流）、`public/cinematic/`（影像）、`public/fonts/`（字体及 OFL 许可）。

## 运行

需要 Node.js 22.12+。

```bash
npm ci
npm run dev
```

访问终端中的 Local 地址（默认 http://localhost:5173）。

```bash
npm run build
npm run preview
```

`npm run build` 先执行 TypeScript 检查，再输出静态站点至 `dist/`。不要直接以 file:// 打开 HTML，模块必须通过 HTTP 服务加载。

## 三维展厅操作（/explore）

- 左键拖动或单指拖动：环绕旋转；滚轮或双指手势：缩放。
- 双击产品表面：平滑聚焦被点击的世界坐标位置。
- 「复位」：恢复初始 45° 镜头并合拢部件；「自动展示」：缓慢环绕旋转，再次点击暂停，手动操作镜头也会暂停。
- 右侧可选择正面、侧面、背面、顶部及 45° 轴测视角。
- 点击模型上的编号热点，查看材料、工艺及概念重建说明。
- 材质研究切换衣装表面 PBR 参数，涵盖原始 CMF、金属、皮革、织物、塑料。金属冠饰、面部等保留自身材质；这些选项用于材质对比，不代表实际产品另有对应版本。
- 摄影棚、暖色展陈、暗黑工业灯光实时切换。
- 「概念部件分解」将外观组按方向平滑分离。它只是几何概念模型的分层演示，不代表实际制造装配工序或机械内部。
- 底部的细节、CMF、设计解读标签可切换阅读内容；细节卡片会定位到对应热点。


## V2 模型精修

当前版本在第一版的展示与交互框架上重做了外观模型：

- 用不对称弯曲、渐细的发束替换规则椭球，并批量生成真实几何细纤维；较窄视窗将发丝预算从 18000 降为 8000；毛领额外采用合批短纤维。
- 面部使用包覆在三维头部曲面上的原创程序化刺绣纹理，包括深棕瞳色、眉形、绣线和腮红；减少眼部塑料感。
- 衣装加入叠襟、腰带扣、前片、袖口、鞋边、披风褶皱、内衬、双层包边与绒毛领。
- 云纹包含颜色、凹凸与粗糙度贴图；冠饰重做镂空轮廓，挂环增加双圈与织带连接，钱饰增加方孔、边圈与浅浮雕示意，红色流苏增加分股。
- 材质预设切换时完整重建对应材质，显式恢复颜色、贴图、凹凸与光泽，避免预设恢复不完整。
- 发丝、毛领和流苏使用合批几何，接触阴影在部件过渡后重新计算并缓存；静止采用按需渲染，旋转、自动展示、镜头和分解过渡持续渲染。
- 热点改为主 React DOM 中的投影标签，避免独立 HTML 根节点卸载时的开发模式告警。

本版本没有添加外观不确定的精密内部结构，没有使用展板照片充当模型。所有新纹理为代码生成的设计近似，仍不是经过实物确认的生产模型。钱饰字样是示意字形，不作古文字准确性声明。

查看 [精修验收说明](docs/MODEL_REFINEMENT.md)。

## 模型依据与限制

展板能识别：黑色绒发、米肤色面部、棕色刺绣眼睛、金色冠饰与挂环、黑金云纹披风、方孔钱胸饰、红色流苏及兵符式挂饰。本页采用独立三维几何体、程序化织物微起伏和云纹表达这些外观特征，未将二维产品图片贴到立方体表面。

**二维图无法提供准确三维曲面、裁片、背部细节、内部连接或尺寸。** 当前原型与展板效果有明显差异，不是可生产的数字孪生，不声明 12 cm 等实物尺寸准确。真实绒毛、针脚、镀层、接缝和连接结构需要三维资产与实物资料补充。下方材质视觉是程序化工艺示意。

## 导入 / 替换真实模型

点击右侧「导入 GLB / GLTF」：

1. 推荐导入内嵌纹理的单文件 `.glb`。
2. `.gltf` 请同时选择主文件、`.bin` 以及所有 PNG/JPG/WebP 纹理；允许使用数据 URI。
3. 资源按文件名匹配。配套资源文件名必须唯一（不同文件夹中存在同名纹理时请导出为 GLB）。外部网络资源不会自动下载。
4. 总文件限制 100 MB；建议面数低于 100k、贴图 2K 或更低，以保证移动设备性能。
5. 模型自动居中、按最长边归一化并显示在展台上，保留原始 PBR 材质。此操作仅在浏览器内完成，不上传文件；刷新后回到概念模型。
6. 可点击「返回墨墨概念模型」。导入错误会保留当前模型，并显示错误提示。

未包含 Draco / Meshopt 压缩和 KTX2 解码器，请导出未压缩 GLB、标准 glTF PBR 与 PNG/JPEG/WebP 贴图。动画、骨骼动画播放及模型内部结构推断不在本 MVP 范围。

导入模型的视角、拖动、缩放、聚焦、灯光和自动展示仍可用。热点、概念分解与材质覆盖会停用，以免把占位模型的数据错误应用到真实产品。要启用真实模型热点及爆炸结构，需要提供命名部件、局部坐标和确认过的分解方向，再配置数据。

### 固定替换为线上资产

将真实模型及其纹理放入 `public/models/`，在 `src/lib/modelLoader.ts` 的加载模块中增加 URL 加载入口，使用同一个 GLTFLoader、归一化逻辑与 `setModel` 数据通道。无需重写展厅、控制面板或镜头模块。当前提供的是直接可用的本地文件替换入口。

## Vercel 部署

仓库包含 `vercel.json`。在 Vercel 导入此 Git 仓库，选择 Vite，构建命令 `npm run build`，输出目录 `dist`。Node.js 请选择 22 或更高，无环境变量与后端服务要求。也可在有 Vercel 登录权限的环境执行 `npx vercel`。

## 已知边界

- 进入三维展厅时才加载约 299 KB gzip 的 3D 模块；构建保留该模块大小警告，不影响编译。DPR 限制为 1–1.6，环境贴图 128、阴影 1024。
- 三维展厅需要 WebGL 2 与硬件加速；叙事首页不依赖 WebGL。展厅提供不支持、渲染失败及上下文丢失提示。
- 全屏遵循浏览器 API 与设备支持情况。
- 绒毛与刺绣为概念近似，PBR 不是照片级还原。
- 本版本为纯静态前端，无账户、数据库或文件持久保存。

## 验证

新增 `scripts/verify-cinematic.mjs` 浏览器验收脚本，覆盖真实音频信号、有声/静音切换、自动滚动与暂停、手动接管、章节与细节、键盘操作、弹窗、移动端、减少动态效果、3D 按需加载与往返。使用独立安装的 Playwright 执行，不增加网页运行依赖：

```bash
# 一个终端先运行 npm run build && npm run preview
# 在已安装 Playwright 的环境运行：
node scripts/verify-cinematic.mjs
# 可配置 PREVIEW_URL、CHROMIUM_PATH、PLAYWRIGHT_MODULE、SCREENSHOT_DIR。
```

字体采用本地 Noto Serif CJK SC 子集，原许可位于 `public/fonts/OFL.txt`。新增中文文案可回退系统字体；如要完整覆盖，可用 FontTools 重新生成子集。

`npm run build` 通过 TypeScript 检查与 Vite 构建。使用环境已有 Chromium/Playwright 对 WebGL、视角、材质、灯光、自动展示、复位、分解、热点、信息标签、错误模型、GLTF+BIN、GLB 与 390px 布局进行浏览器检查。软件 WebGL 环境不代表真实手机 GPU 帧率，真机触控与性能仍建议在目标设备验收。
