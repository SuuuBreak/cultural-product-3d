# 本版影像

本目录的三张 WebP 是 2026-10-22 依据用户上传的「寻秦 · 七萌织锦 / 墨墨」设计展板制作的 AI 概念影像。它们用于网页美术方向和交互叙事验收，并非实物摄影、准确三维还原或生产工艺证明。

- `momo-hero.webp`：黑金摄影氛围、石台、角色整体主视觉；同时用于角色章节的局部取景。
- `momo-craft.webp`：云纹、方孔钱与流苏的概念微距。
- `momo-life.webp`：皮包挂饰的概念生活场景。

构图在网页中通过 CSS 取景与缓慢变换展示，图片没有用于冒充可旋转的三维模型。源图仅作格式压缩，不额外合成文字或 UI。替换为正式摄影时可使用同名 WebP，并根据新构图调整 `cinematic.css` 的取景位置。原三维展厅独立位于 `/explore`。

声音直接在浏览器中合成；这里没有第三方音乐文件。
